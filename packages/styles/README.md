# @usezeno/styles

Sass variables for the single-file components in `@usezeno/vue`. `build.mjs`
generates them from `@usezeno/tokens`, with the names the 2025 code base used.

New code does not need this package. Use the custom properties in
`@usezeno/tokens/css`. This package goes away when the Vue single-file
components do.

Pre-release: the variable names can change in any 0.x minor release.
