# Tokens and theming

Every colour, space, radius, type size and duration in Zeno is a design token.
The tokens live in `@usezeno/tokens` as JSON, and Style Dictionary builds them
into a stylesheet and a JavaScript module. There are <TokenCount /> of them.
The tables on this page are built from that package and drawn with the tokens
themselves, so they always show the current values.

## Load the stylesheet

Load the stylesheet once per page, before any Zeno element renders:

```js
import '@usezeno/tokens/css';
```

It defines each token as a custom property that starts with `--zeno-`. The
Zeno elements read those properties and carry no fallback values. An element
on a page without the stylesheet has no colours or spacing.

## Light and dark

Light is the default theme. The stylesheet switches to dark when the operating
system asks for dark. To override that, set `data-theme`:

| Markup                      | Result                                    |
| --------------------------- | ----------------------------------------- |
| `<html>`                    | Follows the operating system              |
| `<html data-theme="light">` | Light, whatever the operating system says |
| `<html data-theme="dark">`  | Dark, whatever the operating system says  |

`data-theme` also works on any element, and themes that element and
everything inside it:

```html
<section data-theme="dark">
  <zeno-button>Dark, on a light page</zeno-button>
</section>
```

`@usezeno/core` exports helpers that set the attribute for you:

```js
import { getTheme, setTheme, onSystemThemeChange } from '@usezeno/core';

setTheme('dark'); // sets data-theme="dark" on <html>
setTheme('system'); // removes the attribute
getTheme(); // 'light' or 'dark', after resolving 'system'
const stop = onSystemThemeChange(theme => console.log(theme));
```

### Colour families

The colour families are `accent`, `neutral`, `success`, `warning`, `danger`
and `info`. Each one has the same eight tokens:

| Token                       | Use                                          |
| --------------------------- | -------------------------------------------- |
| `solid`                     | A filled control or shape                    |
| `solidHover`, `solidActive` | The same fill when hovered or pressed        |
| `onSolid`                   | Text and icons on the solid fill             |
| `subtle`, `subtleHover`     | A tinted background                          |
| `border`                    | An outline in the family colour              |
| `text`                      | Coloured text on a page or subtle background |

| State    | Tokens                                                                             |
| -------- | ---------------------------------------------------------------------------------- |
| Hover    | `color.background.hover`, `color.border.controlHover`, `solidHover`, `subtleHover` |
| Active   | `color.background.active`, `solidActive`                                           |
| Selected | `color.background.selected`                                                        |
| Focus    | `color.focus.ring`, `focus.ring.width`, `focus.ring.offset`                        |
| Disabled | `color.text.disabled`, `color.background.disabled`, `color.border.disabled`        |
| Invalid  | `color.text.invalid`, `color.border.invalid`                                       |

## Change the accent

The theme tokens point at palette steps, so you can re-theme by overriding a
few properties after the Zeno stylesheet:

```css
:root {
  --zeno-color-accent-solid: #0f766e;
  --zeno-color-accent-solid-hover: #115e59;
  --zeno-color-accent-solid-active: #134e4a;
}
```

Zeno checks its own colour pairs for contrast. It cannot check yours, so test
any colour you override against the text and backgrounds it appears with.

## Fonts

The font tokens name IBM Plex Sans and IBM Plex Mono first, followed by system
fonts. Zeno ships no font files. Load IBM Plex yourself if you want it. If you
do not, the system fonts apply.

## Contrast

The token package tests a list of colour pairs against WCAG 2.2 AA in both
themes: 4.5:1 for text, and 3:1 for control boundaries, focus rings and filled
shapes. The list is in `packages/tokens/test/contrast-pairs.mjs`, and the test
runs as part of `pnpm test`.

Disabled controls and decorative separators are not in the list. WCAG exempts
them from these two criteria.

## Use tokens in JavaScript

```js
import { tokens, light, dark, vars } from '@usezeno/tokens';

tokens.spacing[4]; // '1rem'
light.color.text.primary; // the resolved light value
vars.color.text.primary; // 'var(--zeno-color-text-primary)'
```
