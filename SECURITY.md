# Security

## Report a vulnerability

Do not open a public issue or pull request for a security problem.

Report it privately with GitHub's private vulnerability reporting:
[github.com/cipherlabs-hq/zeno/security/advisories/new](https://github.com/cipherlabs-hq/zeno/security/advisories/new).

Say which package and version, what an attacker could do, and the smallest
markup or code that shows it.

## What to expect

Zeno is maintained by Cipher Labs, a small company. No response time is
promised. A fix is released as a new version and listed in the changelog.

## Supported versions

Only the latest release gets fixes. They are not carried back to older
versions.

## Scope

The `@usezeno/*` packages and the code in this repository.
